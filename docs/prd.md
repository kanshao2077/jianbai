# 见白需求文档

## 1. 工具概述

### 1.1 工具名称
见白

### 1.2 工具描述
一个支持多版本对照的深度写作工具，体现从混沌走向清晰的写作哲学，数据完全本地存储。

## 2. 核心功能

### 2.1 多栏写作布局
- 四栏横向排列：素材、初稿、二稿、定稿
- 每列包含独立的全高度Textarea编辑器
- 支持Markdown语法输入
- 独立垂直滚动条，互不干扰

### 2.2 列状态管理
- 折叠/展开功能
- 折叠时显示竖排标题，宽度60px
- 展开时显示完整编辑区域

### 2.3 数据持久化
- 实时保存到LocalStorage
- 500ms防抖机制
- 页面刷新自动恢复内容
- 四个存储键：writer_material、writer_draft1、writer_draft2、writer_final

### 2.4 自定义子标题功能
- 每列顶部增加单行输入框，用于用户给当前内容命名
- 无边框透明背景设计
- 粗体显示，颜色为text-gray-500
- Placeholder默认为"无标题"或"点击命名"
- 数据自动保存到LocalStorage
- Key命名：writer_title_material、writer_title_draft1、writer_title_draft2、writer_title_final

### 2.5 辅助功能
- 关于/哲学模态框：展示工具哲学理念
- 复制定稿：一键复制定稿内容到剪贴板
- 重置功能：清空所有内容并重置LocalStorage

## 3. 技术要求

### 3.1 技术栈
- 前端框架：React
- CSS框架：Tailwind CSS
- 图标库：Lucide React
- 纯前端实现，无后端依赖

### 3.2 布局规范
- 全屏容器：高度100vh，宽度自适应
- 每列最小宽度400px
- 横向滚动条处理
- Flex弹性布局

## 4. 设计风格

### 4.1 配色方案
- 素材列：bg-stone-200（最深暖灰）
- 初稿列：bg-stone-100
- 二稿列：bg-orange-50（极浅暖白）
- 定稿列：bg-white（纯白）
- 同色系渐进式设计，体现写作进程

### 4.2 字体排版
- 全局使用衬线字体（Serif）
- 字号：text-lg
- 行高：leading-relaxed
- 模拟纸质阅读感
- 主Logo使用粗体现代无衬线字体（font-bold, tracking-tight）

### 4.3 视觉细节
- Textarea去除边框和聚焦轮廓
- 编辑器模拟无限长纸张效果
- 折叠按钮使用Chevron图标
- 一致的阴影和圆角设计
- 模态框采用半透明背景和白色卡片
- 自定义子标题采用无边框透明设计，粗体显示

## 5. 参考技术实现

### 5.1 数据持久化实现
- 使用useEffect监听输入变化
- 500ms防抖处理
- LocalStorage读写操作
- 页面加载时自动恢复状态
- 包含新标题数据的存储和读取
\n### 5.2 布局实现
- Tailwind CSS网格布局
- min-width约束和横向滚动
- Flexbox弹性布局
- 响应式处理
- 在每列标题和编辑器间插入子标题输入框

### 5.3 交互实现
- 折叠/展开状态管理
- 独立滚动区域配置
- Markdown语法支持
- 素材列纯文本模式
- 子标题输入框焦点管理和Placeholder显示

### 5.4 辅助功能实现
- 模态框组件
- 剪贴板复制API
- 浏览器确认对话框
- 重置状态逻辑
