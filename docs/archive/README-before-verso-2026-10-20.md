# verso.

拒绝跳转，平行视野。

verso.是一个纯本地的四栏写作工作台，专门解决写文档时“反复横跳”的痛苦：素材、初稿、二稿、定稿并排展开，不用在窗口、Tab 和文档段落之间来回切换。

现有线上版本（本地 verso. 改版尚未发布）：

https://kanshao2077.github.io/jianbai/

## 🤯 为什么做它

写文档最烦的不是打字，而是视野被打断。

- ❌ 写一个文档要参考好几个材料，切来切去，切过去又忘了自己要看什么。
- ❌ 做方案 A/B 对比时，只能在一个文档里上下滚，逻辑容易断。
- ❌ 想改一段话又怕改废，只能复制一堆“备份段落”，最后文档越来越脏。

verso.的解决方式很直接：把写作过程摊开。左边放素材，中间做迭代，右边收定稿。让对比、修改和推进发生在同一个视野里。

## 🎯 它适合什么场景

- 写方案、复盘、汇报、邮件、公众号草稿。
- 把零散素材整理成结构化文档。
- 同时对比多个版本，不想反复滚动查找。
- 想改稿但又不想污染原文。
- 办公环境不方便使用云端编辑器，只想要一个本地可用的写作台。

## 💡 核心功能

- ✅ 四栏分屏：SOURCE、DRAFT、EDIT、FINAL 并排处理，一眼看完整个写作链路。
- ✅ 本地自动保存：内容保存在当前浏览器本地，不需要登录，也不依赖后端服务。
- ✅ Markdown 友好：支持标题、强调、链接、列表、引用、代码块、普通表格和任务清单的输入与粘贴。
- ✅ 一键复制：聚焦某一列后，复制当前列的 Markdown；选中文字复制也保留 Markdown 结构。
- ✅ 一键清空：需要重写时，可以清掉本地保存的内容，通过更多菜单里的 `Reset workspace` 操作，并可点击 `Undo` 恢复四列标题与正文。
- ✅ 折叠列：暂时不用的列可以收起，给当前写作区让空间。
- ✅ 精简工具栏：常驻复制和更多按钮；菜单提供全屏、单栏专注、About 和工作区重置。
- ✅ 单栏专注：专注编辑当前列，按 Esc 返回四栏；内容与各列滚动位置保持不变。

## ⚙️ 体验细节

- 🟠 橙色标记：呼吸圆点在编辑标题或正文时亮起，不作为保存成功提示。
- 📐 博朗风格：克制、低噪音，把注意力留给文字。
- 👻 轻量滚动条：正文滚动时短暂出现，停止后隐藏。
- 📊 参数化统计：每列实时显示字符计量，方便控制篇幅。

外观会跟随系统自动切换浅色与深色，无需刷新。四栏正文、标题、滚动条、选区与提示消息均适配两种模式；键盘导航保留可见焦点，并尊重系统的减少动态效果设置。

浅色以中性白和极浅灰为主，橙色用于光标与状态点缀。英文优先使用 Helvetica Neue，中文使用苹方；正文 16px、行高 1.7，四栏统一灰白底色与 32px 水平留白；进入单栏时，阅读宽度受限并居中显示。连续输入时工具淡出，悬停或键盘访问即可恢复，参考文字保持清晰。

### Markdown 输入

- 输入 `- [ ] ` 或 `- [x] ` 可创建未完成／已完成的任务，点击复选框切换状态。
- 输入表头（例如 `| 项目 | 状态 |`），换行输入 `| --- | --- |` 后按 Enter，可创建普通表格。Tab 切换单元格，在末尾按 Tab 追加一行。
- 也可以直接粘贴完整 Markdown 表格或任务清单。
- 普通表格复制为管道表格，单元格里的 `|` 会正确转义。合并单元格、多段落等复杂表格保留为 HTML，避免压平内容；这不等于支持所有 Markdown 扩展语法。

## 💾 数据说明

verso.不是云文档。

内容只保存在当前浏览器的本地存储里。换电脑、换浏览器、清理浏览器数据，都可能导致内容丢失。重要内容写完后，请及时复制到你自己的正式文档或仓库里。

这个设计是有意为之：少一点账号、同步和权限问题，多一点直接可用。

## 🛠️ 本地运行

需要先安装 Node.js，建议 20 或以上版本。

```bash
npm install --no-package-lock
npm run dev
```

打开终端里显示的网址，就能在本地预览。

## 📦 打包

```bash
npm run build
```

打包结果会生成在 `dist` 目录。

## 🚀 部署到 GitHub Pages

只要把代码推送到 `main` 分支，GitHub 会自动打包并发布到：
